# Wildrange model asset credits

The following 3D meshes are bundled and modified in Wildrange.

- Deer by Polyfork (https://polyfork.dev/asset/deer-base), CC BY 4.0.
- Pig by Polyfork (https://polyfork.dev/asset/pig-base), CC BY 4.0. Recoloured and adapted with additional boar details for Wildrange.
- Bolt-Action Rifle by Polyfork (https://polyfork.dev/asset/bolt-action-rifle-2f1793), CC BY 4.0.
- Marksman Rifle and Bipod by 3DAssets.dev (https://3dassets.dev/assets/fps-survival-forest-outpost-weapon-marksman-rifle-e20c7bc2), CC0 1.0 Universal.
- Forest Boar, Jointed by 3DAssets.dev (https://3dassets.dev/assets/fps-survival-forest-outpost-creature-boar-2eae041a), CC0 1.0 Universal.
- White-Tailed Deer high-detail static source by Grab3D (https://grab3d.com/models/animals/deer/), CC0 1.0 Universal. Imported for future retopology and rigging; not used as a live game model.

## Build-time CC0 architecture and vegetation assets

The following models are public domain under CC0 1.0 Universal. They are fetched into the browser build by `scripts/download_licensed_3d_assets.sh`, rather than stored as binary files in the source repository.

- Log cabin 3 x 3 m, apex roof — Innerscene 3D Parts Library (https://www.innerscene.com/tools/library/3d-parts/log-cabin-3-x-3-m-apex-roof-ed7532ac). Used as the authored exterior model for Pinecrest Lodge. The existing Wildrange interior furniture, interactive door, porch and compound systems remain in the scene.
- Conifer, detailed needles — Innerscene 3D Parts Library (https://www.innerscene.com/tools/library/3d-parts/conifer-detailed-needles-ca8e7cef). Used for high-detail conifer trees near the compound.
- Linden street tree, detailed leaves — Innerscene 3D Parts Library (https://www.innerscene.com/tools/library/3d-parts/linden-street-tree-detailed-leaves-6300c26e). Used for high-detail broadleaf trees near the compound.

The CC0 dedication permits use, modification and redistribution, including commercial use, without attribution. The source links are retained here for provenance and asset maintenance.
